## Validation Report

- **Source**: 230-run unified CUDA experiment matrix
- **Overall Confidence**: CAUTION
- **Reason**: 数据与设计完整、效应巨大且跨种子总体稳定；但只有五个 seeds、N80 来自离散预算网格，并存在少量训练波动。

### 完整性与一致性

- 230 个唯一 runs，230 个 `status=completed`。
- LeNet 和 ResNet-18 各包含 ERM 40、GroupDRO 40、DFR 35。
- 无重复 key、缺失格、NaN、错误 rho 或错误 N80 标记。
- 全部配置统一为每类 5,000 张、10 epochs、batch size 256、seeds 0–4。
- ERM checkpoint 共 80 个；GroupDRO/DFR 按存储策略不保留 checkpoint。
- 训练日志行数：ERM 80×10、GroupDRO 80×10、DFR 70×30，全部有限值。

### Statistical Findings

| Finding | Evidence | Interpretation | Confidence |
|---|---|---|---|
| N=0 存在强颜色捷径 | ERM aligned accuracy 约 99%，conflict accuracy 约 5–7%，flip rate 约 93–95% | 高 aligned accuracy 不能说明模型学习了形状 | SOLID |
| GroupDRO 跨架构稳定 | 两个模型 median N80 均为 500，range 250–500 | 在当前设置下对架构变化较稳健 | SOLID |
| DFR 存在架构交互 | LeNet median N80=250；ResNet-18=1000 | DFR 的 sample efficiency 取决于 backbone 表示 | SOLID |
| ERM threshold 波动较大 | 两模型 median N80=1000，但最大均达到 2500 | 精确临界点有 seed variability | CAUTION |
| 阈值敏感性总体稳定 | 70/80/90% 分析仅使 LeNet-ERM 的 90% threshold 上升 | 主要排序不是单一阈值的人为产物 | SOLID |

没有报告 p-value。五个 seeds 不足以支持复杂渐近检验；主报告使用 raw seed points、mean±SD、median/range 和配对效应大小。

### Warnings

| Type | Detail | Affected |
|---|---|---|
| Coarse threshold grid | N80 是最小观测预算，不在相邻预算间插值 | 所有 N80 |
| Small seed count | 每格只有五个 seeds | SD、range 与方法差异精度 |
| Training instability | ResNet-ERM 的 N=0/seed1 和 N=100/seed2 最终 validation accuracy 分别为 94.83% 和 89.75% | 两个 run；原样保留以避免选择性删除 |
| Group information | GroupDRO 与 DFR 使用已知 conflict/group 信息 | 对现实未知偏差的外部有效性 |
| Synthetic benchmark | Colored MNIST 只有一个受控颜色捷径 | 对自然图像和多重捷径的外推 |

### Fallacy Scan

- **Coverage**: 11/11 fallacy types checked

| Fallacy | Severity | Finding |
|---|---|---|
| Simpson's Paradox | NOTE | 已按模型、方法和 seed 展开；总体改善方向与大多数组内方向一致，但 DFR 的架构交互必须单独报告。 |
| Ecological Fallacy | NOTE | 推断单位保持为模型/run，不从组平均推断个体人群行为。 |
| Berkson's Paradox | NOTE | 样本未按模型结果筛选；MNIST 平衡抽样由设计预先固定。 |
| Collider Bias | NOTE | 分析没有加入由方法和结果共同造成的控制变量。 |
| Base Rate Neglect | NOTE | 数字类别和颜色边际均被显式固定；指标不是诊断筛查概率。 |
| Regression to the Mean | NOTE | 预算不是依据极端模型表现选择，所有预设预算均完整运行。 |
| Survivorship Bias | NOTE | 230/230 runs 均完成；两个低 validation runs 没有删除。 |
| Look-Elsewhere Effect | NOTE | 主指标、预算和 N80 在实验前确定；70/90% 仅作为标注清楚的敏感性分析。 |
| Garden of Forking Paths | CAUTION | 训练轮数在 pilot 后锁定为 10；最终报告必须保留该决策历史，不能再根据主结果换 checkpoint。 |
| Correlation != Causation | NOTE | N 与颜色是受控干预，反事实测试支持对该合成设置的因果解释；不可外推为现实模型的一般因果机制。 |
| Reverse Causality | NOTE | 反例注入发生在训练前，结果不可能反向决定预算。 |

### Reproducibility

- **Method**: 116 个本地 MPS 与 CUDA 重叠 runs 的环境敏感性比较。
- **Verdict**: PARTIALLY_REPRODUCIBLE。
- Conflict accuracy、flip rate、consistency 和 worst-group accuracy 的跨环境相关系数约为 0.998、0.998、0.996 和 0.982。
- 少数 GroupDRO worst-group 值差异较大，LeNet-ERM 的 N80 中位数也由本地 2500 变为 CUDA 1000。
- 因此最终主分析只使用统一 CUDA 的 230-run 矩阵；本地 MPS 结果保留为 pilot，不与主表混合。
- 未在同一 CUDA runtime 上执行第二次完全独立重跑，所以本报告状态为 `ANALYZED`，不是 `VERIFIED`。

### Validation Verdict

实验完整性足以进入论文写作。最可靠的结论是：颜色捷径效应巨大；GroupDRO 跨架构稳定；DFR 的效果具有明显架构依赖。精确 N80 应始终伴随 seed range 和离散预算限制，不应表述成普遍常数。
